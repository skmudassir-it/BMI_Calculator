# 🧮 BMI Calculator

> A simple Body Mass Index calculator built with Flask.

**⚠️ This project has been replaced by a modern Next.js version:**

### 👉 [bmi-calculator-next](https://github.com/skmudassir-it/bmi-calculator-next)

The new version features:
- 🎨 Animated BMI gauge meter
- 📊 Color-coded categories (Underweight / Normal / Overweight / Obese)
- 🌐 Metric & Imperial unit support
- 📝 Calculation history (saved to localStorage)
- ⚡ Built with Next.js 16 + Framer Motion + Tailwind CSS

---

## Old Version (Flask)

```bash
pip install -r requirements.txt
python app.py
```

Formula: `BMI = weight(kg) / (height(cm) / 100)²`
